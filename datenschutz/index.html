1. Verantwortliche Stelle

EU-Fahrschule
Kontakt: Kontaktformular

2. Daten bei einer Anfrage

Wenn Sie das Kontaktformular nutzen, verarbeiten wir die von Ihnen eingegebenen Angaben, um Ihre Anfrage zu beantworten. Dazu können Name, E-Mail-Adresse, Telefonnummer, Wohnort, gewünschte Führerscheinklasse, Zeitraum und Nachricht gehören.

Zur technischen Übermittlung wird der Formulardienst FormSubmit eingesetzt. Die eingegebenen Daten werden über diesen Dienst an unsere E-Mail-Adresse weitergeleitet. Alternativ können Sie uns direkt per E-Mail kontaktieren.

3. Zweck und Speicherdauer

Die Angaben werden nur zur Bearbeitung Ihrer Anfrage und für die damit verbundene Kommunikation verwendet. Sie werden gelöscht, wenn sie dafür nicht mehr erforderlich sind und keine gesetzlichen Aufbewahrungspflichten entgegenstehen.

4. Technische Daten

Beim Aufruf der Website kann der Hostinganbieter technische Zugriffsdaten verarbeiten, die für einen sicheren Betrieb erforderlich sind. Diese Website setzt selbst keine Analyse- oder Marketing-Cookies.

5. Ihre Rechte

Sie können Auskunft, Berichtigung oder Löschung Ihrer personenbezogenen Daten verlangen. Nutzen Sie dazu unser Kontaktformular.

6. Datensparsame Anfrage

Bitte senden Sie über das Formular zunächst keine Ausweis- oder Führerscheinkopien. Falls Dokumente später erforderlich sind, stimmen wir den Übermittlungsweg mit Ihnen ab.
